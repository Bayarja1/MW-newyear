# Ид шидийн өртөө

Хамт олны шинэ жилийн арга хэмжээний React/Vite frontend + Node.js/SQLite backend.
Демо хэрэглэгч, зохиомол оноо, өдөр болон эрх солих товч байхгүй. Ажилтан өөрөө бүртгүүлэхгүй; зөвхөн админаас үүсгэсэн эрхээр нэвтэрнэ.

## Локал ажиллуулах

Node.js **22.15+**, pnpm ашиглана. SQLite нь Node-ийн `node:sqlite` модулиар ажиллана (Node 22 дээр experimental анхааруулга гарна).

```sh
pnpm install --frozen-lockfile
pnpm dev
```

Frontend: http://localhost:8443, API: http://127.0.0.1:3001. Frontend-ийн `/api` хүсэлтийг Vite proxy дамжуулна.

Бэлдсэн production хувилбар:

```sh
pnpm build
pnpm start
```

http://127.0.0.1:3001 дээр frontend, API хоёул ажиллана.

## Эрхүүд

Энэ компьютерийн `data/` санд хүсэлтээр үүсгэсэн **18 ажилтан + 1 админ** бий. Ажилтны нэвтрэх нэр `employee01`–`employee18`; нэрсийг хэрэглэгчийн өгсөн дарааллаар оруулсан. Админ `admin`.
Нууц үгсийг зөвхөн **`data/private-access.csv`** хувийн файлаас авна. Сервер нууц үгийг scrypt хэшээр хадгална; админд ч хуучин нууц үг харагдахгүй. Бүртгэл хэсгээс өөрийн нууц үгийг солино. Админ ажилтны нууц үгийг шинэчлэх боломжтой.

Шинэ, хоосон өгөгдлийн санд админ үүсгэх:

```sh
pnpm admin:create
```

Нэр, имэйлтэй CSV-ээс ажилтан үүсгэх (шуудан илгээхгүй):

```sh
pnpm accounts:import /absolute/path/employees.csv /absolute/private/path/private-access.csv
```

CSV толгой: `name,email,department`. Нэвтрэх нэр нь имэйл; нууц үг санамсаргүй үүснэ. Гарах файл байвал дарж бичихгүй. Үүссэн файлыг ажилтан бүрт зөвхөн өөрийнх нь мэдээллээр дамжуулна.

## Арга хэмжээ бэлдэх

1. Админаар нэвтэрч «Ажилтнууд» хэсэгт нэр, хэлтэс, хүн бүрийн **3 баримт** оруулна.
2. «Бэлгүүд» хэсэгт **18 бэлэг**, тус бүрийн 2 сэжүүр нэмнэ.
3. «Хуваарь» хэсэгт эхлэх **даваа гарагийн огноо**, өдөр бүр нээх цаг, баасан гарагт захиа/оноо нээх цаг тохируулна. Улаанбаатарын UTC+8 цаг ашиглана.
4. «Тойм → Оноолтыг үүсгэж бэлдэх» үйлдэл: хүн бүрт өөрөөс нь бусад 10 хүний асуулт, эхний захианы нэг хүлээн авагч онооно. Хүн бүрийн баримт тэнцүү тоогоор таарна; хүн бүр нэг системийн захиа авна. Бэлтгэсний дараа оролцогч, баримтыг солихгүй.
5. «Сорил» хэсэгт шинэ жилийн 5, компанийн 5 асуулт оруулна. 4 сонголт, зөв хариулт, хугацаа, тайлбарыг тохируулна. Эхлэхээс өмнө асуултаа засах/устгах/дээш зөөх боломжтой.
6. Лхагва гарагт админ «Шууд сорил» хэсгээс эхлүүлж, хариулт нээж, дараагийн асуулт руу шилжинэ. Ажилтнууд төхөөрөмж бүрээсээ нэгдэнэ. Серверийн нэг төлөвийг секунд тутам асууж синк хийнэ; 8 секунд тутам оролцогчийн heartbeat шинэчлэгдэнэ. Хугацаа дуусвал сервер хариултыг автоматаар нээнэ. Эцсийн сорилыг дахин эхлүүлэхгүй.

## Дүрэм ба өгөгдөл

- Даваа: «Энэ хэн бэ?» 10×10 = 100; бэлэг олоод зураг илгээж админ баталбал 100.
- Мягмар: эхний захиа системийн хүнд, дараагийнх өөр хүнд; эхний 2 өөр хүнд бичсэн захиа тус бүр 50, нийт 100. Нэмэлт захиа оноогүй.
- Лхагва: live quiz 10×10 = 100. Хурд нэмэлт оноо өгөхгүй.
- Пүрэв: шинэ тоглоом/даалгаваргүй.
- Баасан: захиа болон leaderboard тохируулсан цагт автоматаар нээгдэнэ. Админ зөвхөн баасан гарагт эрт нээж болно.
- Нийт **400**. Оноог клиент илгээхгүй; сервер хариулт, захиа, баталгаажуулалтаас бодно.
- Захианы агуулгыг сервер AES-256-GCM-ээр шифрлэнэ. Админ API агуулга буцаахгүй. Баасан нээгдсэн хойно зөвхөн хүлээн авагч уншина. Серверийн дискийг удирддаг хүн DB болон түлхүүрт хүрэх боломжтой; энэ нь end-to-end encryption биш.
- SQLite transaction + UNIQUE хязгаарлалтууд бэлэг/хариулт/оноо давхардахаас хамгаална.
- Фото нь зөвшөөрөгдсөн зураг формат, 5 MB хүртэл; зөвхөн эзэн болон админ үзнэ. Зураг, ноорог, захиа, оноо сервер дээр хадгалагдана.
- Нэвтрэлт HttpOnly/SameSite cookie, 12 цагийн session; role-ийг сервер шалгана. Алдаатай login оролдлогыг хязгаарлана. Өөр домэйны write хүсэлт зөвшөөрөхгүй.

## Сервер дээр ажиллуулах

```sh
pnpm install --frozen-lockfile
pnpm build
NODE_ENV=production APP_ORIGIN=https://YOUR-DOMAIN HOST=127.0.0.1 PORT=3001 DATA_DIR=/srv/dogdlol-data pnpm start
```

HTTPS reverse proxy-оор Node руу дамжуулна. `APP_ORIGIN` нь браузерын яг ашиглах origin байна. Production cookie `Secure` тул HTTPS шаардлагатай. Нэг Node процесс + тогтмол диск ашиглана. SQLite-г serverless-ийн түр диск дээр байрлуулахгүй. Proxy дээр upload хязгаарыг 5 MB-ээс багагүй тохируулна.

**Шинэ сервер рүү зөөхдөө Git код хангалтгүй:** `data/`-гийн DB, шифрлэлтийн түлхүүр, шаардлагатай WAL файлуудыг хувийн сувгаар зөөнө. Онлайн нөөцлөлтөд SQLite backup API ашиглах, эсвэл процессыг зогсоож `data/` хавтсыг бүхэлд нь хувийн backup хийнэ. `letters.key` алдагдвал захиаг тайлахгүй. Энэ хавтас болон нууц үгийн CSV нь Git-д орохгүй.

## Шалгалт

```sh
pnpm typecheck
pnpm test
pnpm build
```

Integration тест тусдаа түр DB дээр HTTP хүсэлтээр: нэвтрэлт, админ эрхийн тусгаарлалт, 18 ажилтны шударга оноолт, бэлгийн нэг удаагийн оноолт, зураг шалгалт, нууц захианы хугацаа/эзэмшигч, live quiz-ийн хариулт/давхардал, 400 онооны хязгаар, CSRF болон logout-ыг шалгана. Бодит хэрэглэгчдийн санд тест өгөгдөл нэмэхгүй.

## Админы гараар нээх / хаах

«Удирдлага → Хуваарь»-аас 5 өдөр тус бүрийг хуваарийн дагуу, гараар нээлттэй, эсвэл гараар хаалттай болгоно. Тохиргоо DB-д хадгалагдаж, огнооноос давуу үйлчилнэ. Давааг нээхэд хоёр тоглоом, мягмарыг нээхэд захиа бичих, лхагвыг нээхэд live quiz, баасныг нээхэд захиа унших/leaderboard ажиллана. Пүрэв нь амралтын цонх хэвээр, даалгаваргүй. Тоглоомын оноолт бэлтгэгдсэн байх шаардлагатай; гараар нээхэд эхлэх огноо заавал тохируулсан байх албагүй.

Ажилтнуудын төлөв 10 секунд тутам, quiz 1 секунд тутам шинэчлэгдэнэ. Хаахад сервер шинэ үйлдлийг шууд хориглоно. Өмнөх оноог устгахгүй, quiz-ийн хугацааг pause хийхгүй. Нээсэн захиаг дахин хаахад өмнө нь уншсан мэдээллийг буцааж нууцлах боломжгүй.
